Dynamic Form Building Website using Django

Key Features:
Form Creation (Admin):

Admin users can create unlimited forms.
Each form can have up to 100 questions.
Admins can choose from various question types (e.g., Text, Dropdown, Checkbox).
Admins can configure question options (for Dropdown/Checkbox questions).
Admins can order questions within the form.
Form Submission (End User):

End users can submit responses to forms anonymously.
Users can submit responses an unlimited number of times.
Analytics:

Admins can view analytics for each form:
Text Field: Distribution of the top 5 most common words.
Checkbox: Distribution of the top 5 option combinations.
Dropdown: Distribution of the top 5 selected options.
Question Types:

Text: Open-ended text input.
Dropdown: Single-choice from predefined options.
Checkbox: Multiple-choice from predefined options.
Future Enhancements: Ranking, Linear Scale, Date Picker, Time Picker, File Upload, Matrix/Grid, Image Choice, Slider, Signature Capture, Color Picker, Geolocation, Percentage Allocation.
Admin Panel:

Django’s built-in admin panel is used for managing forms and questions.
